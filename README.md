# Karuthal Architects — UI prototype

Static mockup for client review: `index.html` (home), `projects.html` (work index, filters + sketch-to-photo hover), `project.html` (project detail).

Hatched boxes are photo placeholders. To add a real photo on the Projects page, put it in `images/` and set `photo` in the `projects` array in `projects.html`.

Deploy: Vercel → Import this repo → Framework "Other", no build command, default output directory.
